# MSSQL Connector for Adobe ColdFusion

This folder is designated for the MSSQL connector required for Adobe ColdFusion. Developers should place the MSSQL connector files here to ensure proper integration and functionality within the test environment.

You can download the MSSQL connector from the following link: [MSSQL Connector Download](https://learn.microsoft.com/en-us/sql/connect/jdbc/download-microsoft-jdbc-driver-for-sql-server?view=sql-server-ver17)
