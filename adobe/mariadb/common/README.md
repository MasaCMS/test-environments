# MariaDB Connector for Adobe ColdFusion

This folder is designated for the MariaDB connector required for Adobe ColdFusion. Developers should place the MariaDB connector files here to ensure proper integration and functionality within the test environment.

You can download the MariaDB connector from the following link: [MariaDB Connector Download](https://mariadb.com/downloads/connectors/connectors-data-access/java8-connector)
